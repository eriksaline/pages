# Example Blog Post

This is an example blog post to show you the Liquid Blog in action!

## Getting Started

To create your own posts, use the **Admin Dashboard** at `http://localhost:3000`:

1. Fill in the post title and content
2. Add an author name and tags
3. Click "Create Post" to save as draft
4. Click "Publish" to make it live

## Markdown Support

This blog supports standard **Markdown** formatting:

### Headers
Use `#`, `##`, `###` for different heading levels.

### Text Formatting
- **Bold**: `**text**` or `__text__`
- *Italic*: `*text*` or `_text_`
- ~~Strikethrough~~: `~~text~~`

### Lists

**Bullet List:**
- Item 1
- Item 2
- Item 3

**Numbered List:**
1. First
2. Second
3. Third

### Code

Inline code: `const x = 42;`

Code blocks:
```javascript
function hello() {
  console.log('Hello World!');
}
```

### Links and Images

[Visit LiquidJS](https://liquidjs.com)

### Blockquotes

> This is a blockquote.
> It can span multiple lines.
